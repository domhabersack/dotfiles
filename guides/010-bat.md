# bat: colorized cat, man pager, and fzf previews

## What changed

When [bat](https://github.com/sharkdp/bat) is installed, `zshrc` wires it into three places:

- `cat` is aliased to `bat --paging=never` — syntax-highlighted output, but still dumps straight to the terminal like plain `cat` rather than opening a pager.
- `$MANPAGER` pipes man pages through bat (`col -bx | bat -l man -p`) for highlighted man output.
- fzf's Ctrl-T file picker gets a live preview pane (`FZF_CTRL_T_OPTS`) that renders the highlighted file content of whatever's currently selected.
- `BAT_THEME=ansi` makes bat render with the terminal's own 16 ANSI colors rather than a built-in theme. This one env var covers all three uses above (bat reads it on every invocation).

Install with `brew install bat`. All three are guarded by `command -v bat` — nothing changes if it isn't present.

## Why it helps

Syntax-highlighted file contents are easier to scan than plain text — indentation, strings, and keywords stand out immediately. The fzf Ctrl-T preview means you can see what's in a file before you pick it, instead of picking blind and opening it to check.

## When to use it

No new commands — just keep using `cat file`, `man command`, and Ctrl-T in the shell as before. The improvements apply automatically once bat is installed.

## What to look out for

- The alias is set once at shell start, so installing bat mid-session won't take effect until you open a new shell (or re-source `zshrc`).
- `cat` is aliased with `--paging=never` specifically so it keeps behaving like `cat` (dumps and returns). Calling `bat` directly (unaliased) still pages by default.
- `$MANPAGER` piping through `col -bx` first strips the backspace-based bold/underline sequences `man` emits, which bat would otherwise render as literal characters.
- `BAT_THEME=ansi` is deliberate: bat's default theme assumes a dark background, so on a light terminal its light foregrounds wash out and become hard to read. `ansi` defers to the terminal's own palette, so bat stays readable whatever theme the terminal uses. To use a named theme instead (e.g. on a consistently dark terminal), set `BAT_THEME` to one from `bat --list-themes`.
